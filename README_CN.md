这是一个面向 Home Assistant 2025.10.0+ 的企业级虚拟设备集成，**支持一台设备下创建多个同类型实体**。

它为测试、演示、开发和学习提供完整的设备模拟环境。

**如果这个项目对你有帮助，欢迎点一个 Star 给予支持。**

## ✨ 核心特性

- 🎯 **一设备多实体**：一个设备包含1-10个相同类型实体，完美模拟真实设备
- 🛠️ **29种设备类型**：覆盖智能家居所有主要设备类别
- 🎨 **图形化配置**：Web界面分步向导，支持批量配置
- 📊 **模板系统**：动态计算传感器数值、媒体内容、图像生成
- 💾 **状态持久化**：自动保存和恢复设备状态
- 🧺 **完整洗护模拟**：洗衣机和烘干机包含程序选择、延时启动、控制按钮和核心运行传感器
- 🌍 **多语言支持**：完整的中英文界面
- 🔧 **企业级质量**：HACS Silver认证，严格遵循HA规范
- ⚡ **高性能**：异步操作，优化资源使用
- 🎮 **自动化友好**：丰富的事件触发和状态反馈

### 🧺 洗护设备实体组

洗衣机和烘干机不是单一开关，而是按完整家电设备组提供。每个洗护设备会自动生成：

- `switch`：电源控制
- `select`：程序选择，以及洗衣机温度/脱水转速或烘干机烘干目标
- `button`：开始、暂停、恢复、停止
- `number`：延时启动分钟数
- `sensor`：运行状态、剩余时间、总时长、进度、完成时间
- `binary_sensor`：门状态、远程启动、远程控制

### 🚗 车辆实体组

车辆支持三种子类型：**燃油车**、**电动车**、**电动自行车**。每个车辆跨最多 9 个平台暴露实体：

- `lock`：车门锁
- `sensor`：速度、里程表、外部/内部温度、油量与续航（燃油车）、电池电量/续航/电压/电流/电机功率/温度（电动车和电动自行车）、充电速度/充电器功率/电压/电流/充电量/充满时间（电动车）、胎压×4（燃油车和电动车）、机油寿命与冷却液温度（燃油车）、预估续航、助力等级/充电次数/电池健康度/双电池/GPS精度/骑行时间/使用天数/行程距离（电动自行车）
- `binary_sensor`：4个车门、后备箱、引擎盖、驻车制动、胎压报警×4、引擎/电源状态、用户在场（燃油车和电动车）；充电中、充电线连接（电动车）；灯光、刹车（电动自行车）
- `switch`：除霜、哨兵模式、充电、座椅自动空调（左/右）、方向盘加热、车厢过热保护（电动车）；灯光、喇叭（电动自行车）
- `select`：驾驶模式；座椅加热×5（前排左/右、后排左/中/右）、方向盘加热（电动车）
- `button`：闪灯、鸣笛；唤醒、无钥匙驾驶（电动车）
- `number`：目标温度；充电限值、充电电流（电动车）；限速、助力等级（电动自行车）
- `climate`：车厢空调控制（燃油车和电动车）
- `cover`：后备箱、天窗、车窗（组控+4个独立）、前备箱、充电口盖（电动车）

### 🍽️ 家电设备实体组

洗碗机、冰箱和门铃同样按完整家电设备组提供：

**洗碗机：**
- `sensor`：运行状态、剩余时间、总时长、完成时间
- `binary_sensor`：门状态
- `switch`：电源
- `select`：程序（eco、auto、强力、快速、冲洗）
- `button`：开始、暂停、恢复、停止
- `number`：延时启动分钟数

**冰箱：**
- `sensor`：冷藏室温度、冷冻室温度、模式
- `binary_sensor`：冷藏门、冷冻门
- `switch`：电源
- `select`：模式（正常、eco、速冷、度假）
- `number`：冷藏室温度、冷冻室温度

**门铃：**
- `sensor`：最后响铃时间
- `binary_sensor`：运动检测
- `select`：铃声（经典、数字、威斯敏斯特、静音）
- `button`：响铃
- `camera`：门铃摄像头，支持运动检测和夜视
- `event`：响铃、运动、按键

## 🚀 快速开始

### 安装方法

#### 方法1：通过HACS安装（推荐）
1. 打开 **HACS → 集成**
2. 搜索 **"虚拟设备集成（多实体）"** 并安装
3. 重启Home Assistant

#### 方法2：手动安装
1. 下载 [最新版本](https://github.com/ha-china/virtual_devices/releases)
2. 解压到 `config/custom_components/virtual_devices/`
3. 重启Home Assistant

### 添加设备

1. 进入 **设置 → 设备与服务 → 添加集成**
2. 搜索 **"虚拟设备集成（多实体）"**
3. 按照向导完成配置
